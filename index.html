Configure sua chave da YouTube API

Esta ferramenta busca músicas reais no YouTube com filtros pedagógicos automáticos. Precisa de uma chave gratuita da YouTube Data API v3 — configurada uma vez, fica salva no navegador.

  1. Acesse console.cloud.google.com
  2. Menu → APIs e serviços → Biblioteca
  3. Busque YouTube Data API v3 → Ativar
  4. Credenciais → + Criar credencial → Chave de API
  5. Copie a chave AIzaSy... e cole abaixo

Cota gratuita: 10.000 unidades/dia — cada busca usa ~100 unidades (~100 buscas/dia, mais que suficiente para uso diário em sala).
